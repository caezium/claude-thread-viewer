# Thread Library has moved to cc-tools

Thread Library is now maintained in **[caezium/cc-tools](https://github.com/caezium/cc-tools)** as `cc-threads`.

The new home includes conversation search, handoff previews, and explicit launch actions for Codex CLI and T3 Code. It continues to exclude archived and deleted desktop Code threads.

## Install or update

```sh
brew install caezium/tap/cc-tools
cc-threads
```

If you already have cc-tools installed, run `brew upgrade caezium/tap/cc-tools`.

For a source installation and the complete usage guide, see **[Thread Library in cc-tools](https://github.com/caezium/cc-tools/tree/main/lib/cc_threads)**. Report issues and contribute improvements in that repository.
